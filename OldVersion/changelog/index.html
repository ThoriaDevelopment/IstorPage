2026-09-19

The site was rebuilt as v2, and the rebuild is the reason the rest of this entry exists. It is a source tree with a build step now rather than a hand-edited page, which is what let the markup stop shipping its own reasoning: twenty-one comments, 7,768 bytes that arrived with every document and explained the page to nobody reading it. Three gates run before anything lands, and they check that every link resolves, that no page claims a release which does not exist, and that every byte of the artifact is the byte the design plan says it is. That last check is what forced the honesty: the library said "seventy-five other pages" and showed sixteen, so /library/ is a generated directory of all of them, read from each page's own title and summary. Eight comparison pages set out a licence and an install path Istor does not have, and the button at the top of every one of the seventy-five led to a releases page GitHub reports as empty. Both were corrected rather than reworded. The exhibits were audited against their own pixels, and the claims that did not match were corrected with them. On a phone the app's text was arriving at 7.6 pixels, so four exhibits now carry art-directed crops that render it at its native size, which is also why what a phone downloads fell, 257 KB to 217 KB. The close gained a horizon drawn from the calendar ring's own geometry, the hero window answers three questions now, the third a refusal, and the library's header finally has the theme control its stylesheet has been carrying rules for since it was written.
